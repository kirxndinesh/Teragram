# Teragram macOS functional polish — 2026-10-26

Windows/Android conversion and release publication are paused. The current deliverable is the local macOS application, using the existing local desktop account/session identity.

## Changes

- Native New-menu actions remain mounted through WebKit's null focus transitions. Outside pointer/focus and Escape still dismiss the menu. Global uploads resolve to Saved Messages; a folder view retains its destination. Folder selection recursively queues its contents, with archive upload retained as an explicit settings preference.
- The old default of six concurrent uploads migrates to two. Large resumable uploads send one part at a time, with a 120-second deadline per RPC and up to three exponentially delayed retries for transient transport errors. Authorization and account-change errors are not retried. Existing resumable checkpoints and encrypted envelopes remain intact.
- Floating sidebar state, controls and styles are removed; legacy persisted values are discarded. The brand is the accessible collapse/expand button. Docked 248/68-pixel rail state and Cmd/Ctrl+B persist.
- The supplied rounded blue SVG supplies the header, favicon and bundle artwork. The monochrome macOS tray template remains separate.
- Gallery zoom changes responsive column widths, with bounded file-grid tracks. Small still-image thumbnails progressively upgrade through a two-request queue. Image zoom and pan stay inside the floating viewer frame.
- The account menu and account settings share owner-scoped Telegram name, username/phone, initials and photo data. Native profile responses validate the captured account/session before publication; a small photo is cached in the owner's workspace store.
- PDFs retain the existing PDF.js range-loading/lazy-page pipeline inside the floating viewer, with page navigation, zoom, fit width and download. Canvas resolution accounts for Retina displays with a bounded pixel budget.
- UTF-8 text/code files up to 2 MB open in a virtualized read-only viewer with line numbers, basic syntax coloring, wrapping and Copy Text. Markup is rendered as text, never executed. Very long individual lines bypass token highlighting to bound DOM work.
- PSD/PSB/AI files request Telegram document thumbnails independently of MIME classification. When needed on macOS, bounded Quick Look decoding produces a flattened rendition. PDF-compatible AI files use the OS PDF provider. Sources remain unchanged; this does not provide layer editing or guarantee a decoder for every Illustrator variant. Local fallback source limits remain 16 MB for thumbnail generation and 64 MB for display renditions.

## Verification and limits

Browser journeys run the real application and providers with controlled native/Telegram boundaries. The native upload journeys exercise local storage, resumable/encrypted streams, transfer admission, cancellation and publication payload construction with a controlled Telegram transport. Real Telegram upload throughput/socket recovery requires a live acceptance transfer and is not established by these fixtures.

The native creative journey uses the actual macOS Quick Look decoder on a synthetic PSD, its embedded thumbnail, a missing-thumbnail fallback, and a synthetic PDF-compatible AI document. No personal files are uploaded by this verification.

The upload suite requires FFmpeg on macOS, as documented in TESTING.md. Initial broader runs without it had 17 passing and 8 failing journeys; a private test-only FFmpeg tool supplied that prerequisite and all 25 upload journeys then passed. It is ignored build tooling and is not added to the app or published.

The local release bundle is `app/src-tauri/target/release/bundle/macos/Teragram.app`. The native window connected to the existing account and displayed the real name and username. After the Mac was unlocked, native UI checks confirmed that Upload File opens the macOS file picker, Upload Folder opens the directory picker, and Create Folder opens the channel-creation dialog. All three were cancelled after inspection, and Teragram was left open. No Windows/Android build, Git push or release publication was performed during this polish pass.

Reviewed total CSS is 187,239 bytes against an adjusted 188,000-byte ceiling; all JavaScript, locale and feature ceilings remain enforced. Final build reports are generated by the normal bundle-budget check.

Final verification record: all **67 browser journeys passed** in the complete final run, including PDF rendering/zoom/fit width/download, native clipboard invocation and legacy preference removal. All **25 native upload journeys passed** with the declared FFmpeg prerequisite, including the final retry-account guard. The creative native journey passed with real OS decoding. TypeScript, localization/literal budgets, app-security configuration, Rust formatting, E2E policy and production bundle budgets passed. No live Telegram upload was used as acceptance evidence.

## Native follow-up after unlock

The native transfer panel showed a user-initiated local-image upload marked Success. The remaining timeout jobs point to Google Drive sources. Read-only filesystem metadata identifies inspected sources as dataless placeholders, and the native picker labels the affected files Not Downloaded and reports that the Google Drive application could not be found. These sources need to become locally available before their uploads can succeed; increasing Telegram RPC timeouts cannot supply missing source bytes. No additional file uploads or remote folder creation were performed during the picker checks.
